        <CardTitle>Java Edition Connection Guide</CardTitle>
        <CardDescription>Play on PC (Windows, macOS, Linux)</CardDescription>
      </CardHeader>
      <CardContent>
        1. Launch **Minecraft: Java Edition** (Version 1.21.4+ recommended).
        2. Click on **Multiplayer** from the main menu.
        3. Click **Add Server** at the bottom.
        4. Enter **ZHorde** in the Server Name field.
        5. Copy and paste the Server IP above into the **Server Address** field.
        6. Click **Done** and double-click the server to join!
      </CardContent>
    </Card>

  <TabsContent value="bedrock">
    <Card>
      <CardHeader>
        <CardTitle>Bedrock Edition Connection Guide</CardTitle>
        <CardDescription>Play on Console, Mobile (iOS/Android), or Windows 10/11 Bedrock</CardDescription>
      </CardHeader>
      <CardContent>
        1. Launch **Minecraft** on your Bedrock device.
        2. Click **Play**, then select the **Servers** tab.
        3. Scroll down to the bottom of the servers list and click **Add Server**.
        4. Enter **ZHorde** as the Server Name.
        5. Enter the Server IP address from above in the **Server Address** field.
        6. Leave the port as the default Bedrock port (**19132**).
        7. Click **Save** or **Play** to connect!
      </CardContent>
    </Card>
